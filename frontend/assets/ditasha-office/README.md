# DITASHA pixel-office assets

- `desk.png`: `public/sprites/furniture/standing-desk-left-front.png` from https://github.com/W17ant/Claude-Office
- `plant.png`: `public/sprites/decoration/monstera-plant.png` from the same repository.
- Upstream MIT license: `LICENSE-Claude-Office.txt`, copyright 2026 W17ANT. No upstream hook configuration or chat server is installed.
- `team-front.png` and `team-rear.png`: generated with the built-in image generation tool for DITASHA. Original generated PNGs are preserved. `atlas.json` records alpha bounds; SVG viewports select sprites without altering the originals.
- Style reference: the upstream Helper character sheet. Prompt specification: ten full-body isometric office pixel-art characters in a 5 by 2 atlas, charcoal DITASHA varsity jackets with cream sleeves, D chest/back monogram and individual accent colors. Front three-quarter and matching rear three-quarter poses. Transparent background. Row order: Amii, Nara, Rei, Kira, Luna; Sora, Mika, Achi, Lora, Dante. Identity cues: glasses for Amii and Sora, chestnut bob Nara, black spiky hair Rei, ponytail Kira, pink hair/beret Luna, brown buns Mika, white bob Achi, chestnut bob Lora, short black hair Dante.

The room renderer projects DITASHA's existing navigation graph. Art and scene changes do not replace the task scheduler, AI providers or persistent data.
